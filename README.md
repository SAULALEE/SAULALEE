## Proyecto destacado — Katedra AI

> Aplicación web que **genera contenido académico con Inteligencia Artificial** para
> profesores: a partir de un temario produce estructura, teoría, exámenes y diapositivas.

| | | | |
|:--:|:--:|:--:|:--:|
| **37** | **404** | **24** | **205** |
| endpoints REST | tests automatizados | migraciones Flyway | commits |

**Qué construí**

- Aplicación web responsiva con arquitectura **cliente-servidor** y **monolito modular** en
  **React** y **Spring Boot**, con **37 endpoints REST en 7 módulos**: autenticación
  **OAuth2**, suscripciones con **Stripe** y control de acceso por roles vía **JWT**.
- Integré la API Key de **OpenAI** a través de **Spring AI** para generar contenido
  académico. El módulo Temarios usa **14 endpoints** y extrae contenido de archivos y URLs,
  con historial de cambios en **tiempo real**.
- **404 tests automatizados** (336 backend + 68 frontend) en **JUnit 5, Mockito, AssertJ**
  y **node:test**, con base de datos en memoria. Endpoints probados y documentados en
  **Bruno**.
- Desplegué el frontend en **Vercel**, consumiendo el backend en **Render** vía API REST.

**Stack**

`Java 21` · `Spring Boot 4` · `Spring AI` · `Spring Security / JWT` · `OAuth2` · `Stripe`
· `MySQL 8` · `Flyway` · `Docker` · `React 19` · `Vite` · `Tailwind CSS` · `Zustand`
· `JUnit 5` · `Mockito` · `GitHub Actions`

**Enlaces**

[⚙️ API](https://katedra-server.onrender.com/api/v1) (requiere autenticación) ·
