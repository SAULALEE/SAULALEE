## Featured project — Katedra AI

> Web application that **generates academic content with Artificial Intelligence** for
> teachers: from a syllabus it produces structure, theory, exams and slides.

| | | | |
|:--:|:--:|:--:|:--:|
| **37** | **404** | **24** | **205** |
| REST endpoints | automated tests | Flyway migrations | commits |

**What I built**

- Responsive web application with a **client-server** and **modular monolith** architecture
  in **React** and **Spring Boot**, with **37 REST endpoints across 7 modules**: **OAuth2**
  authentication, **Stripe** subscriptions, and role-based access control via **JWT**.
- Integrated the **OpenAI** API Key through **Spring AI** to generate academic content. The
  Syllabuses module uses **14 endpoints** and extracts content from files and URLs, with
  **real-time** change history.
- **404 automated tests** (336 backend + 68 frontend) in **JUnit 5, Mockito, AssertJ** and
  **node:test**, using an in-memory database. Endpoints tested and documented in **Bruno**.
- Deployed the frontend on **Vercel**, consuming the backend on **Render** via REST API.

**Stack**

`Java 21` · `Spring Boot 4` · `Spring AI` · `Spring Security / JWT` · `OAuth2` · `Stripe`
· `MySQL 8` · `Flyway` · `Docker` · `React 19` · `Vite` · `Tailwind CSS` · `Zustand`
· `JUnit 5` · `Mockito` · `GitHub Actions`
